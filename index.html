학번으로 학생을 연결하고, 문제 배점과 워크시트 만점으로 점수를 환산합니다.

처음 5명만 표시합니다.

학생과 점수·감점 사유가 맞는지 확인해주세요. 피드백의 줄바꿈도 함께 확인하세요.

    테스트성명 / 학번성적피드백 댓글

    LearnUs의 ‘채점 워크시트 업로드’에서 CSV를 선택한 뒤 변경 목록을 확인하세요. ZIP 피드백 첨부와는 다른 기능입니다.

    CSV 미리보기

    LearnUs에 올릴 파일을 선택하고, 학생과 점수·피드백이 맞는지 확인해주세요.

    처음 5명을 표시합니다. 파일 내용은 서버로 전송하지 않습니다.

    성명 / 학번성적피드백 댓글

    이 화면은 CSV에 저장된 내용을 보여줍니다. 채점의 정확성은 원본 엑셀과 대조하세요.

    사용방법

    처음에는 1명으로 테스트하고, 점수와 댓글을 확인한 뒤 전체 파일을 올리세요.

    1. LearnUs에서 워크시트 받기

      해당 활동 설정의 ‘피드백 댓글’과 ‘오프라인 채점 워크시트’를 활성화합니다. 채점 화면에서 해당 분반을 선택한 뒤 ‘채점 워크시트 다운로드’로 CSV를 받으세요. 새 활동마다 그 활동의 워크시트가 필요합니다.

    2. 채점 엑셀과 CSV 선택하기

      변환하기 화면에서 두 파일을 선택하고 시트와 분반을 확인하세요. 엑셀은 학번·성명·분반과 ‘1번(10점)’ 또는 ‘1번(5점)’ 형태의 점수 열, 바로 옆 감점 사유 열이 필요합니다. 수식이 있다면 Excel에서 계산하고 저장한 파일을 사용하세요.

    3. 미리보기에서 확인하기

      ‘결과 확인’을 누르면 처음 5명의 점수와 댓글을 보여줍니다. 문제별 점수를 합산하고 LearnUs 워크시트의 만점으로 환산합니다. 예를 들어 엑셀 7/10점은 워크시트 만점이 100점이면 70점입니다. 제외 학생과 기존 점수·댓글 교체 안내도 확인하세요.

    4. 1명 테스트 CSV 올리기

      미리보기의 학생 한 명을 선택하고 ‘선택한 1명 CSV’를 다운로드하세요. LearnUs의 ‘채점 워크시트 업로드’에서 파일을 선택하고, 변경 목록의 학생·점수·사유를 확인한 뒤 확정합니다. 학생의 피드백 댓글에서 줄바꿈이 표시되는지도 확인하세요.

    5. 전체 CSV 올리기

      테스트가 잘 됐다면 ‘전체 CSV 다운로드’로 받은 파일을 같은 메뉴에 올립니다. 최근 변경된 기록 덮어쓰기 옵션은 실제 LearnUs 수정 내역을 확인한 뒤 선택하세요. ZIP 업로드는 피드백 파일 첨부용이며 점수와 댓글을 넣는 기능이 아닙니다.

    변환이 멈추는 경우

    학번 중복, 잘못된 분반의 워크시트, 비어 있는 점수, 감점 사유 누락, 총점 불일치를 확인하세요. CSV는 UTF-8이어야 합니다. 엑셀에만 있고 워크시트에 없는 학생은 제외하고 안내합니다.
